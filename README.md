# Duelo de Cartas Maker

Juego de cartas de Sosinas Corp: crea tus propias cartas, arma mazos y duela contra la IA o con un amigo por internet.

**Jugar:** https://cirrusskstudio-lab.github.io/duelo-de-cartas/

En el celular puedes instalarlo como app desde el menú del navegador (Android: «Instalar app»; iPhone: Compartir → «Agregar a inicio»).
